# Security Policy

**AgentFlow** is an enterprise-oriented AI workflow platform maintained by **SPManchester Private Limited**. We take the security and integrity of our codebase, deterministic execution engine, and user data seriously.

---

## Supported Versions

We provide security updates and patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability or potential risk in AgentFlow, please report it privately. **Do not create public GitHub issues for security vulnerabilities.**

### Reporting Process

1. **Email directly**: Send detailed vulnerability reports to **[info@spmanchester.com](mailto:info@spmanchester.com)**.
2. **Include in your report**:
   - Detailed description of the vulnerability.
   - Steps to reproduce or proof-of-concept payload/code.
   - Impact assessment (e.g., denial of service, privilege escalation, bypass of guardrails).
   - Any recommended remediation steps.
3. **Response Timeline**:
   - An acknowledgement will be sent within **48 hours**.
   - An assessment and proposed timeline will be provided within **5 business days**.
   - A public release containing the fix will be published once verified.

---

## Safe Harbor & Research Guidelines

We encourage responsible security research. We will not take legal action against security researchers who:
- Make a good-faith effort to avoid privacy violations and destruction of data.
- Give us reasonable time to remedy the issue before public disclosure.
- Do not exploit vulnerabilities beyond the minimum necessary to demonstrate proof-of-concept.
